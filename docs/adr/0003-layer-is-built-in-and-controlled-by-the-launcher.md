# The Layer is built into the Mac Build and controlled by the Launcher, not installed as a mod

Upstream ships the Layer as a mod named `repentogon` that appears in the game's MODS list and is on when that mod is on. The Mac Build instead carries the Layer inside the app, the way REPENTOGON's DLL sits outside the mod list on Windows, and the Launcher decides before each start whether it is on (a Vanilla Launch turns it off). This keeps the Layer from being switched off or deleted by accident in the MODS menu and gives the user one place, outside the game, to manage it. The cost is a standing difference from upstream's packaging: Layer updates come from upstream as Lua under `scripts/recomp/rgon/` and must be re-embedded by the Mac build rather than taken as a mod archive.
